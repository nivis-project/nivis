Found while moving the docs site to docs.nivis.tf. The branding spec and docs/BRAND.md still define the old brand: Cinzel and Schibsted Grotesk, navy and Volcanic Ember, the twin-summit emblem and glyph, the TERRAE NIVIS banner, ember CLI splash colours, and the tagline "Infrastructure as Nix Code" with "All your base belongs to Nix". The house style is now nivis.tf: Hind, the curve mark h(theta) = a + b cos k theta, the teal to blue palette, and the tagline "Terraform providers as first-class Nix values."

Pim agreed on 2026-11-19 to do this as a separate change during phase 3 of the GitHub polish briefing (the nivis README rewrite), not together with the docs domain move.
